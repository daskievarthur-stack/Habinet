# Phase 2 — Define the Language of Habinet

Phase 1 established the engineering foundation.

The repository is now stable.

Development tooling is in place.

Automatic formatting, testing and continuous integration are working.

From this point forward, the primary goal is no longer infrastructure.

The goal is to define the language of Habinet.

---

## Objective

Describe reality before implementing it.

The Kernel must define concepts, not applications.

Applications emerge from the Kernel.

---

## Phase Goals

- Complete the Kernel Ontology.
- Define the Kernel Map.
- Finalize the Kernel Primitives.
- Implement the Kernel from the ontology upward.
- Ensure every implementation has tests.

---

## Success Criteria

By the end of Phase 2, Habinet should have a complete, coherent Kernel that can express:

- Mail
- Calendar
- Documents
- Notes
- Tasks
- Chat
- AI
- Future applications

without introducing new fundamental concepts.

The Kernel should already contain everything required.

Applications become compositions of Kernel primitives.
