# Kernel Ontology

> The ontology defines the universe of Habinet.
>
> It is independent of implementation, programming language,
> storage engine, database, or user interface.

---

# Purpose

Habinet is not a collection of applications.

It is a coherent model of reality.

Every feature is built from the same small set of fundamental concepts.

The ontology defines those concepts.

---

# Fundamental Concepts

The Habinet universe consists of seven primitives.

Identity

Grain

Relation

Event

Timeline

Capability

View

Nothing outside these concepts is fundamental.

Everything else is composition.

---

# Identity

Identity answers one question.

> Who is this?

Identity is permanent.

Identity never changes.

Identity never carries behavior.

Identity only identifies.

---

# Grain

Grain answers one question.

> What exists?

Everything that exists inside Habinet is a Grain.

Mail is a Grain.

Document is a Grain.

Person is a Grain.

Company is a Grain.

Task is a Grain.

Meeting is a Grain.

Conversation is a Grain.

Idea is a Grain.

Everything.

---

# Relation

Relation answers one question.

> How are Grains connected?

Relations define structure.

Not hierarchy.

Not ownership.

Connection.

---

# Event

Event answers one question.

> What happened?

Every change is an Event.

No change exists without an Event.

---

# Timeline

Timeline answers one question.

> When did it happen?

Timeline is history.

Nothing has history outside Timeline.

---

# Capability

Capability answers one question.

> What is allowed?

Capabilities define permissions.

Capabilities never define identity.

Capabilities never define data.

---

# View

View answers one question.

> How is reality presented?

Views never own data.

Views never change reality.

Views observe.

---

# Laws

## Law 1

Nothing exists without Identity.

---

## Law 2

Everything that exists is a Grain.

---

## Law 3

Grains never own other Grains.

Grains are connected by Relations.

---

## Law 4

Nothing changes without an Event.

---

## Law 5

Every Event belongs to a Timeline.

---

## Law 6

Capabilities never define reality.

They define permissions.

---

## Law 7

Views never own data.

Views only present reality.

---

---

# Design Principle

Whenever a new feature is proposed,
it must first be expressible using the ontology.

If it cannot,
either the feature is wrong,
or the ontology must evolve.

The ontology always comes first.
